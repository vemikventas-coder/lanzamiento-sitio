# lanzamiento-sitio

Recursos estáticos del sitio de **LANZAMIENTO** (imágenes, texturas, recortes y fuentes) que usan los bloques de código instalados en Webador (`lanzamiento.com.mx`).

- Se publican con GitHub Pages en `https://vemikventas-coder.github.io/lanzamiento-sitio/`.
- Esta carpeta la genera `12-LANZAMIENTO/sitio/build/build-webador.mjs --copiar=…`: no se edita a mano.
- Fotos y renders de Machen: propiedad del cliente. Imágenes del catálogo Time Ceramics: uso sujeto a confirmación del cliente. Fuentes: SIL Open Font License 1.1. Detalle en `12-LANZAMIENTO/sitio/LICENCIAS.md`.
